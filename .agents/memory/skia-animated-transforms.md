---
name: Skia animated transforms
description: Non-obvious React Native Skia and Reanimated constraints for the game’s native render path.
---

For this Expo Go runtime, do not pass a Skia picture through a Reanimated shared value. On native Android/iOS, publish steady-state pictures with the internal `SkiaViewApi.setJsiProperty(nativeId, "picture", picture)` followed by `requestRedraw(nativeId)`; keep the React `picture` prop only as a mount/race fallback. `setPicture()` is a web handle method and must not be called on the native ref. Build paths with `Skia.PathBuilder`, not `Skia.Path.Make()` mutation methods.

**Why:** Shared matrix selectors crashed the Reanimated recorder, direct selectors produced invalid float errors, and the shared picture path produced an invalid `SkTextBlob` plus a React re-entrancy error in Expo Go. Updating the native picture through React state on every frame could pin the game loop near 30 FPS; the native JSI property path avoids that render churn. Skia 2.11 also emits a LogBox warning for mutable `SkPath` methods. On Android, a 60-particle destruction burst crossed a native frame-pressure threshold and left the refresh rate at 30 FPS; updating the large SVG layer when a capture committed had the same risk.

**How to apply:** Keep the game-loop and allocation optimizations independent from renderer changes. Build pictures in the game loop, publish them through the native view API at a bounded cadence, and explicitly request a redraw. If the native view is not mounted yet, use one React `picture` prop update and switch to JSI publication afterward. Keep claimed polygons and protected trails in the Skia picture rather than the large React/SVG layer, so capture start/commit does not trigger a native tree update. Publish the React snapshot only when static dimensions or sector change. On Android, drive the game loop with a 60 Hz timer rather than `requestAnimationFrame`, which was observed to settle at 30 Hz independently of JS workload. Keep split/destruction bursts below the measured particle threshold and rate-limit repeated mini-ship escape searches near protected trails.
